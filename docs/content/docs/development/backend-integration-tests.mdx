# 后台集成测试

后台集成测试使用独立的 Docker Compose 项目、PostgreSQL、MinIO 和模拟 AI 供应商。它不会请求真实模型，不会产生供应商费用，也不会读取或修改本地开发数据库与对象存储。

## 运行测试

确保 Docker 已启动，然后在 `server/` 目录执行：

```bash
npm run test:integration
```

测试命令会自动完成以下操作：

1. 删除上一次遗留的测试容器和测试数据卷。
2. 构建当前代码对应的前端与后台镜像。
3. 启动名为 `infinite-canvas-test` 的隔离 Compose 项目。
4. 自动执行数据库迁移和幂等 seed。
5. 运行 Node 集成测试。
6. 无论成功或失败，默认删除测试容器、网络和数据卷。

如果需要保留失败现场：

```bash
KEEP_TEST_STACK=true npm run test:integration
```

排查完成后手动清理：

```bash
docker compose -f ../docker-compose.test.yml -p infinite-canvas-test down --volumes
```

macOS 找不到 Docker CLI 时，可以显式指定：

```bash
DOCKER_BIN=/opt/homebrew/bin/docker npm run test:integration
```

## 自动覆盖范围

当前共 19 项断言，归纳为 18 组业务场景：

- 全新环境自动迁移、seed、管理员登录及前后台健康检查。
- 同一 `requestId` 并发提交 20 次只产生一个任务和一条计费记录。
- 用户普通并发、视频并发和模型全局并发严格执行限额。
- 排队和运行中取消时状态保持一致，并以函数级用例验证取消后的真实用量可以覆盖 0 元占位记录。
- 日调用限额、月度金额限额、额度周期重置和管理员豁免。
- 无价格、规格单价未命中、模型能力与计价类型不匹配时，在供应商调用前拒绝。
- 零单价、视频按秒计费但缺少时长、音频只有分钟价而没有字符兜底时拒绝配置或调用。
- 在途任务固定使用创建时的价格规则，追溯新增价格只影响之后创建的任务。
- `calculationDetail.lines` 与结算金额一致，新增价格规则不会修改历史账单。
- 输出数量、Token、视频时长、消息和提示词硬上限，以及供应商失败后的稳定任务与 0 元记录。
- 生成 60 次、上传签名 120 次的频率限制，以及每用户 100 条待上传记录上限。
- 普通用户不能访问管理接口，用户之间不能读取任务、项目或上传文件。
- 停用账号、修改密码后的多设备会话撤销、8–16 位密码边界及状态修改请求来源校验。
- 文件声明大小、实际大小、真实 MIME 类型和跨用户 `uploadId` 校验。
- 下载签名过期后失效，重新查询任务可获得新的有效地址。
- 供应商响应期间终止后台容器，重启后遗留任务变为失败并留下 0 元记录，账号数据继续保留。
- 整个 Compose 项目执行 `down` 后重新 `up`，数据库任务与 MinIO 生成文件继续存在。
- 自动 seed 在已有管理员密码不符合新建规则时仍可执行，并且容器重启不会覆盖后台修改过的渠道配置。

测试使用 `server/tests/mock-provider.mjs` 模拟文本、图片和延迟视频响应。通过提示词中的 `[delay=毫秒]` 控制响应窗口，便于稳定复现并发和取消竞态。

## 仍需人工验收

以下行为依赖真实浏览器环境，不由后台集成测试代替：

- 在画布中生成图片后，确认浏览器可直接加载 `S3_PUBLIC_ENDPOINT` 签发的结果地址。
- 使用非 `localhost` 的 HTTP 地址访问时确认 Cookie 行为。生产环境必须使用 HTTPS，并保持 `SESSION_COOKIE_SECURE=true`。

后续还可增强两类精确时序测试：音频和视频成功任务的端到端媒体结算，以及取消请求与供应商结果提交在同一时刻发生的真实并发压测。当前测试已分别覆盖计费前置保护、视频并发、取消状态和取消后真实用量覆盖逻辑，但不把这些组合场景表述为完整端到端覆盖。

## 最近验证结果

当前测试栈已完整运行通过：19 项通过、0 项失败。测试结束后测试容器和数据卷已自动清理。
