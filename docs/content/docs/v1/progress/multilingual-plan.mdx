# 多语言支持

状态：实现及 Claude 只读审核已完成，待人工测试确认

## 目标

- 建立可扩展的中、日、英国际化架构。
- 第一阶段保留现有简体中文并完成日语界面。
- 后续增加英语时主要补充翻译资源，不再修改业务组件结构。
- 语言切换不改变已有画布、资产、渠道名称等用户业务数据。

## 当前范围

- Web 全局导航、配置中心和公共组件。
- 首页、画布、图片、视频、提示词、资产及异常页面。
- 浏览器端校验、API 请求错误、成功提示和空状态。
- Agent 面板、对话、历史、日志、工具状态及 Canvas Agent 返回的用户可见文案。
- Ant Design 内置组件、日期时间格式、HTML 语言属性和中日文字体。

## 暂不处理

- 自动翻译用户输入、提示词、画布内容或历史数据。
- 自动翻译模型生成的文本内容。
- 自动翻译关键词、提示词正文、用户输入、资产标题或模型输出；这些业务内容始终保留原文。
- 为插件作者提供完整的第三方翻译包协议；第一阶段只处理内置功能。
- 使用带语言前缀的路由，例如 `/ja/canvas`。

## 验收标准

- 用户可以在偏好设置中选择简体中文或日语，选择立即生效并在刷新后保留。
- 日语模式下，目标范围内的应用自有界面、状态和错误均显示日语。
- 第三方接口返回内容、用户数据和 AI 生成内容不会被自动翻译或覆盖。
- 简体中文模式保持现有功能与文案含义。
- 翻译资源缺失时有明确回退，不显示原始 key。
- 增加英语时无需逐个改动已经迁移的 React 组件和业务服务。
