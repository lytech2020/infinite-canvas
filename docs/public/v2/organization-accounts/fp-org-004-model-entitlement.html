1. 文档信息

状态：确认済。最终可用模型为平台启用、公司授权、成员授权且存在可用渠道的交集。

2. 功能点输入整理

目的平台按公司出售或授予模型权益，公司管理员再控制员工可用范围
新行为公司模型集合、成员模型集合、默认模型、授权回收
范围外公司自建模型定义、公司修改参数规范、成员自行添加模型

13. 日志 / 监查 / 运用设计

记录授权前后模型 ID 集合、操作者、公司和成员；监控已授权但无可用渠道或无生效价格的模型。

14. 外部接口 / 文件 / 批处理 / 通知

不调用供应商模型列表决定授权；授权依据平台已登记模型。授权回收不取消已进入供应商的任务，但服务端立即阻止新任务。前端不依赖推送：登录/切号后重取，模型选择器在页面聚焦或缓存 TTL 到期时重取；生成返回 MODEL_NOT_ENTITLED、MODEL_ROUTE_UNAVAILABLE 或 MODEL_PRICE_UNAVAILABLE 时强制刷新并清除失效默认值。

15. 数据迁移 / 初期数据 / 兼容性

不默认将全部模型授权给全部公司。测试环境可用显式 seed 列表初始化；生产由平台管理员逐公司授权。

16. 测试设计观点

  • TEST-FP-ORG-004-001：平台启用、公司授权、成员授权、可用渠道/价格四条件交集正确。
  • TEST-FP-ORG-004-002：公司回收模型后成员授权残留也不能使用，重新授权后按保留的 enabled 状态恢复。
  • TEST-FP-ORG-004-003：公司管理员不能越权修改自己、company_admin、其他公司成员或公司集合外模型。
  • TEST-FP-ORG-004-004：默认模型失效时按成员→公司→平台交集链重算；仍无默认时要求用户显式选择，不静默切换收费模型。
