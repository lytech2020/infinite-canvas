# 项目任务与需求

本目录用于记录尚未完成的产品任务、需求范围、实施步骤和验收标准。

## 使用规则

- 每个较大的任务单独放在 `tasks/` 下，以 Markdown 清单拆分实施步骤。
- `[ ]` 表示待处理，`[x]` 表示已完成；正在处理或阻塞时在条目末尾注明状态和原因。
- 完成一项后立即勾选对应条目，不等到整个任务结束后统一更新。
- 需求或范围发生变化时先更新任务文档，再继续实现。
- 所有实施项和验收项均勾选后，任务状态才可改为“已完成”。
