# 云端版前端改造

状态：实施中；登录、项目登记、四类生成网关和管理后台界面已接入，待联调验收

## 1. 目标

- 将当前偏本地开发和个人配置的界面精简为普通用户可使用的云端产品。
- 删除用户不需要的本地 Agent、开发者配置、提示词库和 WebDAV 功能。
- 前端不再保存或展示 API Key、Base URL 和模型调用脚本。
- 保留画布、图片、视频、素材、插件、语言、主题和快捷键等核心使用能力。
- 所有 AI 请求改为调用云端后台，并携带用户和画布项目信息。

## 2. 顶部导航改造

### 2.1 保留

- 产品名称和首页入口。
- 我的画布。
- 图片生成工作台。
- 视频生成工作台。
- 我的资产。
- 明暗模式。
- 登录用户入口。

### 2.2 删除

- 提示词库导航及 `/prompts` 路由。
- 配置导航及 `/config` 路由。
- Agent 入口。
- 文档入口。
- 版本更新入口。
- GitHub 入口。

删除导航后，直接访问 `/prompts` 或 `/config` 应跳转首页或返回云端版未找到页面，不能只隐藏菜单。

## 3. 画布顶部改造

### 3.1 保留

- 画布菜单和项目名称。
- 插件入口。
- 精简设置入口。
- 明暗模式。
- 键盘快捷键提示。

### 3.2 删除

- Codex / Agent 连接状态。
- Agent 按钮和右侧 Agent 面板。
- Agent 自动连接和 URL 参数处理。
- 文档、版本和 GitHub 入口。

云端版不应在后台继续尝试连接本地 Canvas Agent，不能只隐藏按钮。

## 4. 画布侧边栏改造

### 4.1 保留

- 画布元素列表。
- 我的资产。
- 创建和选择节点所需的核心入口。

### 4.2 删除

- 提示词库 Tab。
- 公共提示词来源列表。
- 提示词搜索、缓存和定时拉取入口。

删除提示词库不得影响用户自己输入提示词，也不得自动翻译或修改画布内已有提示词正文。

## 5. 精简设置

原“配置与用户偏好”改为普通用户的精简设置。

### 5.1 保留

- 界面语言。
- 后台开放模型中的默认模型选择。
- 必要的图片、视频、文本和音频生成偏好。
- 主题偏好；如果已有独立主题按钮，设置中可以不重复展示。

### 5.2 删除

- 渠道新增、编辑和删除。
- Base URL、API Key、API Version 和 Deployment Name。
- Azure OpenAI、Gemini、火山方舟等协议配置。
- 自定义模型调用脚本和脚本编辑器。
- 配置 JSON 导入和导出。
- 提示词来源管理。
- WebDAV 配置、测试和同步。
- 系统提示词等管理员级配置。

普通用户只能选择后台已经启用并授权给前端的模型，不能自行新增模型。

## 6. 插件功能

PDF 需求要求保留插件入口。

第一阶段建议：

- 保留管理员随前端发布的内置插件。
- 普通用户可以启用或关闭允许使用的插件。
- 删除通过任意 URL 安装插件的能力。
- 删除本地开发插件发现功能在生产环境的入口。

当前远程插件会在浏览器直接执行下载的 JavaScript。云端产品如果允许任意 URL 插件，会产生安全风险，因此是否允许第三方插件仍需确认。

## 7. 登录与用户入口

- 未登录用户可以访问产品介绍页；是否可以浏览本地画布待确认。
- 进入 AI 生成功能时要求登录。
- 顶部显示用户头像或邮箱入口。
- 用户入口包含退出登录。
- 管理员账号显示管理后台入口，普通用户不显示。
- 登录过期时保留当前画布内容，并提示重新登录后继续生成。

## 8. 后台模型接入

前端启动后从后台读取：

- 当前用户可用模型。
- 模型展示名称和能力。
- 用户可以调整的参数和范围。
- 模型自身的文件及生成限制。

前端不得读取：

- API Key。
- Base URL。
- Deployment Name 等实际调用标识。
- 自定义调用脚本。

模型选择器继续按图片、视频、文本和音频能力过滤，现有本地渠道 store 不再作为云端模型来源。

## 9. AI 请求改造

所有图片、视频、文本和音频请求从浏览器直连供应商改为请求云端后台。

画布发起请求时至少提交：

- 稳定的 `project_id`。
- 当前项目名称，供后台保存名称快照。
- 节点 ID 或生成配置节点 ID。
- 后台模型 ID。
- 能力类型和允许的生成参数。
- 已上传参考文件 ID。
- 唯一请求 ID，避免重复提交。

后台返回统一任务 ID、状态、结果和稳定错误代码。

图片和视频工作台请求提交 `source`，第一阶段不要求绑定画布项目。

## 10. 画布项目登记

- 创建无限画布时，同时在后台创建最小项目记录并取得 `project_id`。
- 打开已有画布时确认后台项目记录存在。
- 修改项目名称时同步更新后台名称。
- 删除项目时是否删除后台最小记录和用量关联待确认；历史用量不得因项目删除而丢失。
- 画布正文第一阶段是否仍保存在浏览器，按后台文档待确认项决定。

## 11. 文件上传

- 参考图片、视频和音频先向后台申请限时上传地址。
- 前端直接上传对象存储，生成请求只提交文件 ID。
- 上传前显示类型、大小和数量限制。
- 后台拒绝时使用稳定错误代码显示中文或日语提示。
- 上传失败或取消后清理临时状态。

## 12. 错误与状态

- 登录失效、账号停用、并发过高、文件超限、模型不可用和服务繁忙使用稳定错误代码。
- 前端根据当前语言显示中文或日语。
- 第三方供应商的内部错误和密钥信息不得直接显示给用户。
- 任务状态统一使用排队、生成中、成功、失败和已取消。

## 13. 隐私告知

- 注册或首次使用 AI 功能前，向用户说明其提交的提示词会发送到后台并保存。
- 说明管理员可能查看提示词，用于分析常用关键词、排查问题和优化产品。
- 参考文件和生成内容不作为后台运营分析内容展示。
- 隐私说明提供固定入口，后续调整数据用途时同步更新说明。

## 14. 保留的本地数据能力

第一阶段暂时保留：

- 画布在浏览器中的本地保存。
- 我的资产本地保存。
- 生成结果下载。
- 画布导入和导出。
- 素材导入和导出。

删除的是“应用配置 JSON”导入导出，不是画布和生成结果导出。

长期云端项目和资产存储另行设计。

## 15. 暂不处理

- 提示词商城或提示词翻译。
- 本地 Agent 的云端替代品。
- 完整画布和素材云同步。
