# 云端版产品优化数据清单

状态：待确认

## 1. 目的

在不保存不必要内容的前提下，记录能够帮助判断模型效果、稳定性和用户使用方式的数据。本清单中的“已确定”直接纳入第一阶段，“建议首期”与“可选”由产品确认后再实施。

## 2. 已确定记录

- 每次 AI 调用对应的用户、画布项目、来源入口和时间。
- 实际使用的渠道、模型和能力类型。
- 供应商返回或后台估算的 Token，并明确标记数据来源。
- 图片、视频和音频的实际用量单位。
- 用户提交的提示词原文，供管理员查看和按关键词搜索。
- 关键词和提示词保持用户原文，不自动翻译或改写。
- 调用状态、耗时、错误和供应商请求 ID。

## 3. 建议首期记录

以下数据实现成本不高，而且能直接帮助优化系统。

### 3.1 请求上下文

- 稳定请求 ID、任务 ID、用户 ID、项目 ID和节点 ID。
- 来源页面：画布、图片工作台、视频工作台或其他入口。
- 模型能力：文本、图片、视频或音频。
- 用户界面语言和应用版本。
- 请求、排队、开始和完成时间。

用途：定位具体问题，判断哪些入口、版本和语言使用最多。

### 3.2 生成参数

- 请求生成数量和实际返回数量。
- 图片尺寸、宽高比、质量和风格等公开参数。
- 视频时长、分辨率、帧率和是否包含音频。
- 音频时长、格式、音色和语速。
- 文本模型的温度、最大输出长度等实际开放参数。
- 参考文件数量、类型和大小，只记录元数据，不记录文件内容。

用途：判断用户常用配置，为默认值和模型选择器提供依据。

### 3.3 性能与稳定性

- 排队耗时、首个结果耗时和总耗时。
- 成功、失败、取消和超时状态。
- 标准错误代码、供应商错误分类和重试次数。
- 是否触发并发保护、文件限制或供应商限流。
- 供应商与模型维度的成功率和平均耗时。

用途：发现慢模型、不稳定渠道和主要失败原因。

### 3.4 项目使用情况

- 每个项目的 AI 调用次数、活跃天数和最近调用时间。
- 使用过的模型和能力类型。
- 项目内生成成功率。
- 项目包含的节点数量只记录统计值，不上传完整画布内容。

用途：判断用户在不同类型项目中的真实使用深度。

## 4. 建议后台提供的统计指标

- 日活跃、周活跃和月活跃用户。
- 新用户首次成功生成率和首次成功生成耗时。
- 用户次日、7日和30日回访情况。
- 每个活跃用户的调用次数和 Token。
- 每个项目的调用次数、Token 和活跃天数。
- 各模型的调用量、成功率和平均耗时。
- 各入口和能力类型的调用量占比。
- 最常搜索或使用的提示词关键词；必须支持按语言和时间筛选。
- 常见错误、失败模型、失败参数组合和重试后成功率。
- 供应商实际 Token 与后台估算 Token 的占比和差异。

## 5. 可选记录

这些数据有价值，但可以在第一阶段运行后再决定。

- 用户在提交前切换过哪些模型，以及最终选择哪个模型。
- 用户从创建项目到第一次 AI 调用所花时间。
- 简化后的功能访问事件，例如打开模型选择器、上传参考文件、查看帮助。
- A/B 测试分组和配置版本，用于比较不同默认模型或界面方案。
- 后台自动提取的提示词语言、主题和用途分类。
- 用户主动填写的失败原因、满意度和改进建议。
- 项目类型标签；优先让用户主动选择，不要根据画布内容暗中推断。

## 6. 暂不建议记录

- 用户完整画布正文和所有节点内容。
- 参考图片、视频、音频的长期副本。
- 生成结果的长期副本，除非用户主动保存到云端素材。
- 键盘逐键输入、鼠标轨迹或无明确用途的页面录屏。
- API Key、验证码、访问令牌或供应商密钥。
- 用于广告追踪的跨站标识或精确设备指纹。
- 在普通产品分析记录中长期保存完整 IP 地址。

## 7. 提示词与关键词规则

- 保存用户最终提交给模型的提示词原文，不保存编辑过程中的每次输入。
- 提示词不翻译、不改写，确保管理员看到真实用法。
- 管理员可以按用户、项目、模型、语言、时间和关键词搜索。
- 自动关键词统计属于后续能力；第一阶段先支持原文查看和关键词搜索。
- 查看提示词必须写入管理员审计日志；第一阶段不允许批量导出提示词。
- 用户需要在隐私说明中得知提示词会被保存并用于产品优化。

## 8. 数据保留建议

- Token 和媒体用量记录长期保留。
- 提示词长期保存，不设置自动到期时间。
- 临时参考文件和未保存的生成结果按后台文件策略自动删除。
- 用户注销后的身份数据、提示词和用量记录如何处理，需要结合正式隐私政策再确定。
